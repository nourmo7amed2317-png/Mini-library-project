# My Mini Library
About the Project: My Mini Library is a simple web-based library management application that allows users to manage a collection of books,
Users can add, view, search, and remove books through an interactive interface and The application also displays basic library statistics.

1)Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

2) Features
- View Books: Display all books currently stored in the library.
- Add Book: Add new books while preventing duplicate entries.
- Search Book: Search for a book by title (case-insensitive).
- Remove Book: Delete a selected book after confirmation.
- Library Statistics: Display the total number of books, remaining capacity, and library capacity.

3) Storage
The application uses the browser's localStorage to save book data
This means that the book collection remains saved in the same browser even after refreshing or closing the page.

4)Library Capacity
The library supports a maximum of 100 books.

5) How to Run
1. Download or clone this repository
2. Open the index.html file in a web browser
3. Start managing your book collection!

Interface: The application features a dark-themed interface with purple accents.
Project Goal: To practice fundamental web development concepts, JavaScript functions, array manipulation, user interaction, and browser-based data storage
